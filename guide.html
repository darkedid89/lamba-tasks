Как работать

Коротко из созвона 26.11: как устроено, где что делать, как ставить задачу Claude и какие правила не нарушать.

Как устроено

  • Сервер работает круглосуточно: 24 ГБ памяти, 8 ядер. На нём все боты и агенты. Ты работаешь на нём через VS Code (Remote-SSH).
  • Рабочий стол сервера медленный — видеокарты нет, только процессор. Он нужен, чтобы входить в кабинеты в браузере: eBay, поставщики, Shopify.
  • Что делает сервер сам: обновляет таблицу (отправки, упаковка, эффективность), каждое утро сверяет шипменты, ставит задачи в панели «✅ Задачи», следит за конкурентами и по средам советует цены.
  • GitHub хранит каждое изменение: любое можно откатить. Игорь видит, что ты менял, а его правки подтягиваются к тебе.
  • Один бот — одна задача: шипменты, комплаенс, eBay — отдельные боты.

Где что делать

  • Telegram-бот — мелочи: спросить, поправить запись, «заполни конкурентов». Можно голосом.
  • VS Code — всё, что меняет код и логику: исправить ошибку, докрутить правило, собрать нового агента.
  • Amazon — только руками: цены, шипменты, кейсы. Amazon запрещает автоматизацию, за бота можно получить блокировку аккаунта.

Как поставить задачу Claude в VS Code

  1. Новая сессия, тип Local (не Web). Режим Plan, модель Fable 5.2, усилие Extra high — выше не нужно.
  2. Описать суть: что не так или чего хотим добиться, примеры, что уже проверил. Удобно диктовать — через отдельное приложение для диктовки, кнопка в VS Code работает плохо.
  3. Дописать: «задавай мне вопросы, чтобы план был точным». Для подробного интервью — набрать /grill-me.
  4. Ответить на вопросы и прочитать план. Не нравится — написать, что исправить.
  5. План слишком большой — «укороти: только самое важное, чтобы всё работало, без мелочей». Часто он сокращается вдвое без потерь.
  6. Утвердить план, переключить модель на Opus 5.5 (усилие High или Extra high) и написать «реализуй план». Fable для реализации — дорого.
  7. Пока Claude работает — заниматься другим: большая задача может идти несколько часов.
  8. Проверить результат там, где он виден: в таблице, в боте, на сайте.

Правила

  • Пароли и токены не вставлять в чат Claude. Скопировать и написать «возьми пароль из буфера» или положить в файл и назвать путь.
  • На Amazon — только руками.
  • Покупки (прокси, сервисы) — через Игоря.
  • Бот ошибся — не просто закрыть задачу, а найти, почему, и исправить, чтобы не повторилось.
  • Что-то сломал — откатить через GitHub и написать Игорю.

Таблица: на что смотреть

  • «Отправки на Амазон» — красные строки проверять (задача 2). «В пути» и «доставлено» не трогать: обновляются сами. «Доставлено» — значит, на Amazon появился сток. Даты «можно заказывать до» — для планирования.
  • «📈 Эффективность» — как меняются прибыль, конверсия и возвраты по товарам; внизу панель «✅ Задачи» (задача 3).
  • «🔎 Конкуренты» — ASIN конкурентов и рекомендации по ценам по средам (задача 5).
  • Чат «Шипменты» — утренний отчёт бота по отправкам.
